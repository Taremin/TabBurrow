# TabBurrow v1.4.0 リリースノート

## ✨ 新規機能

- **タブ復元時のミュート（消音）設定機能の追加**: 
  - 保存されたタブを復元（ブラウザで開く）する際、自動的に消音状態で開くことができるようになりました。
  - 個別のタブだけではなく、ドメイングループやカスタムグループ単位でもスピーカーアイコンから一括でミュート設定が可能です。
- **最終アクセス日時の自動更新**:
  - 保存済みのURLにブラウザ上でアクセスした際、自動的にそのタブの「最終アクセス日時」が更新されるようになりました。
  - 管理画面上の並べ替え（アクセス日時順など）にリアルタイムで反映されます。※余計なデータベース書き込みを抑えるため、5秒間のスロットリング（連続更新防止）が組み込まれています。

## 🐛 バグ修正・内部改善

- **Service Worker（バックグラウンド動作）の堅牢性向上**:
  - 拡張機能の起動時およびService Workerサスペンドからの復帰時における重複初期化を防止しました。
  - Service Worker再起動時のアクティブタブ追跡リセット問題や、復元時の競合バグを解消しました。
- **自動テストの安定化**:
  - E2Eテスト実行時における接続リークの修正やライフサイクル最適化を行い、テスト実行の不安定さ（Flakyエラー）を解消しました。

*開発者向け: ミュート機能の追加に伴いIndexedDBスキーマをVersion 8へアップデートしました。また、これに伴う各種型チェックエラーの修正およびドキュメントの更新を行いました。*
